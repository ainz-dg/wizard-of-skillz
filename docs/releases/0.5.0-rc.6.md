# Wizard of Skillz v0.5.0-rc.6

**Experimental prerelease candidate — prepared for review; not yet published.**

## Changes

- Guided TUI overview keeps previous audit results accessible and adds
  **Nuova analisi AI (sessione separata)**. Repeating an audit, including after
  switching providers, uses a new temporary review folder; previous evidence
  reports and staged drafts are not overwritten.
- Account-based Codex CLI now places the global `--ask-for-approval never`
  option before `exec`, preserving `--sandbox read-only`, an isolated working
  directory and the existing no-escalation policy.
- The Codex provider picker accepts an optional exact model ID. Leaving it
  blank uses the installed Codex CLI's default. No Codex model catalog is
  provided or implied.
- Optional semantic audits show per-claim progress, the chosen provider/model,
  and offer **Esc** cancellation. Canceled or failed audits do not commit partial
  results. Ollama/OpenAI-compatible HTTP requests support abort and explicit
  per-request timeout diagnostics; the Ollama model list (TAB) has a separate
  15-second timeout and supports cancellation.
- TUI guidance and documentation distinguish the automatic **offline**
  structural scan from **opt-in** AI triage, preparing drafts and explicit
  human-approved Apply. Small terminals preserve the new rerun choice.

## Verification and limits

Synthetic regression tests cover independent reanalysis, Codex CLI argument
ordering and model selection, cancellation without partial findings, transport
timeouts and model discovery. Public CI runs on Ubuntu (Node 22/24) and macOS
(Node 24).

**A green CI run does not verify real-account Codex CLI compatibility or
Ollama inference on a user's machine.** The original cause of a reported
Ollama stall remains unconfirmed; progress and timeout messages are intended
to make the next real attempt diagnosable. Evidence citations remain
hypotheses requiring human inspection, not semantic proof.

No automatic source writes, new provider integration, or organization-specific
configuration is introduced.

## Install (only after publication)

After the owner publishes this exact candidate as a GitHub prerelease and
the npm registry confirms the tarball, run:

```sh
npx --yes wizard-of-skillz@0.5.0-rc.6
# or follow the latest published experimental prerelease:
npx --yes wizard-of-skillz@next
```

Do **not** interpret this candidate document or its appearance in `main` as
proof that RC6 is already available on npm.
