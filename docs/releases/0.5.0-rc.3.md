# Wizard of Skillz v0.5.0-rc.3 — Experimental prerelease

**Wizard of Skillz** is an open-source, generic, human-controlled tool for
reviewing and maintaining Agent Skills. This is a **prerelease**: features
listed below are available for early evaluation, not production-grade
guarantees. No organization-specific backend or catalog is required.

## Highlights

- **TUI-first experience:** guided project switcher, provider selection,
  skills audit, proposed changes, and documented-domain onboarding.
  The CLI stays available for automation and advanced diagnostics.
- **Existing software-skills workflow:** offline structural checks,
  semantic evidence-assisted review, proposal preview and separate human
  confirmation before supported writes.
- **EXPERIMENTAL — Documented Domain:** select local resources (MD/TXT/YAML/JSON),
  optionally with no existing skills. Wizard can suggest up to three
  source-linked draft skills, including domain vocabulary and audience-aware
  communication guidance. Drafts are NOT installed automatically.
- **EXPERIMENTAL — account-backed providers:** use already authenticated local
  Codex CLI or Claude Code CLI in addition to Copilot and Ollama. These
  transports do not capture account credentials; real-account smoke testing
  and compliance with provider entitlements remain the user's responsibility.
- **Reviewable evidence:** source citations and hashes show provenance,
  **not** proof that a domain rule is functionally correct.

## Known limitations

- No PDF/DOCX domain resources or external documentation connectors yet.
- No automatic domain skill Apply/installation in the experimental path.
- Toolsets are not inferred or executed for resource-first domain reviews.
- No claim of real-login compatibility, domain correctness, or automated
  production readiness without independent manual validation.
- Model requests are explicit and can transfer selected local document text
  to a provider; observe your data handling policies.

## Try it

Requires Node >=22.12. After publication on npm:


```sh
npx wizard-of-skillz@next
```


Or use the tagged GitHub source. Open the TUI in a terminal. Follow the
on-screen prompts to select your project and try the documented-domain mode.

**Release process:** the version on npm must correspond to the verified
archive. The owner approves the GitHub Release; automated npm publishing
via GitHub OIDC is enabled after the one-time initial npm package bootstrap.
