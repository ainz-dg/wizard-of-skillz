# Wizard of Skillz v0.5.0-rc.4 — OIDC publishing validation

**Experimental prerelease. No new user-facing features relative to v0.5.0-rc.3.**

This is a release-engineering-only candidate to confirm that an owner-published
GitHub prerelease starts the existing workflow, passes its release gates, and
**publishes the verified npm tarball automatically via npm Trusted Publishing
(GitHub OIDC)**, without a stored npm token.

## What to verify

- The GitHub tag `v0.5.0-rc.4` points to the exact approved `main` commit.
- GitHub Actions runs tests, audits the package and smoke-tests the tarball.
- The `npm publish ... --tag next --provenance` step actually runs (not skipped).
- The npm registry confirms the same SHA-1/SHA-512 integrity as the verified archive.
- A fresh installation of `wizard-of-skillz@0.5.0-rc.4` succeeds.
- `npx wizard-of-skillz@next` resolves to this prerelease after publishing.

## Included capabilities (unchanged, experimental)

- TUI-first skill auditing and proposal review; CLI remains available.
- Documented-domain proposals from MD/TXT/YAML/JSON resources, with cited
  evidence, human review and no automatic skill installation.
- Account-backed Codex CLI and Claude Code CLI transports, still requiring
  real-account smoke tests and compliance with provider entitlements.

## Known limits

No PDF/DOCX resources or external document connectors. The presence of a quote
in a resource does not prove a domain rule is correct. Real-account provider
behavior and business correctness of domain-generated skills are not validated
by CI. Selecting an LLM may send document excerpts to the chosen provider.

As with every Wizard release, publication is authorized by the owner via
**GitHub Release: published**, never by merging a PR.
