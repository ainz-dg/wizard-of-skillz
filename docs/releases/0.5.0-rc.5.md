# Wizard of Skillz v0.5.0-rc.5

**Experimental prerelease published November 11, 2026.**

## Changes

- Audits can compare a repository with itself when both inputs resolve to the
  same canonical root and use the same non-empty identity. Ambiguous root/identity
  pairs fail before provider setup; inter-repository scope hints are not emitted
  for single-repository audits.
- Analysis files now require the expected claim envelope and matching repository
  identities. Raw batch checkpoints are rejected as audit input.
- Bounded retrieval prefers implementation-like context over earlier comments
  and imports while preserving one excerpt per file. Repeated citations to the
  same source file count as one evidence source.
- Single-repository findings do not recommend promoting or splitting knowledge
  between a repository and itself; uncertain claims remain `REVIEW_REQUIRED`.

## Limits

Retrieval remains lexical and heuristic. File or symbol existence does not prove
that evidence entails a claim. `NEEDS_REVIEW` and `REVIEW_REQUIRED` require human
inspection; this prerelease does not apply skill changes automatically.

Install and launch with `npx --yes wizard-of-skillz@0.5.0-rc.5`, or use
`npx --yes wizard-of-skillz@next` (currently resolving to RC5).
