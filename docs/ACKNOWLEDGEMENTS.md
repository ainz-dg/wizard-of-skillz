# Acknowledgements

Wizard of Skillz's keyboard-first, two-panel review workspace drew **UX inspiration** from [Daylight Commander](https://github.com/sanfilippo-smeup/daylight-commander), a Python/Textual terminal commander by the `sanfilippo-smeup` project, distributed under Apache License 2.0.

Wizard implements its own terminal renderer in JavaScript and does not import or depend on Daylight Commander or Python/Textual. This acknowledgement recognizes a useful design influence; it is not a claim that its source code is included in Wizard.

Wizard's independently authored pixel mascot is rendered in terminal ANSI colors, without bundling a graphics engine or using Daylight Commander's assets.

## Agent Skills design guidance

Wizard's skill-design and agent-evaluation prompts draw on the general writing-for-agents and skill-mechanics guidance published by [Matt Pocock](https://github.com/mattpocock/skills) (MIT-licensed; copyright 2026 Matt Pocock). The guidance is acknowledged as an influence, not an independent verification of any software claim.

Wizard also follows the public [Agent Skills specification](https://agentskills.io/) for the skill format. The software itself is distributed under Apache License 2.0.
